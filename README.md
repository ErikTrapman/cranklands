# Cranklands

Cranklands is an indoor cycling app for Android phones and tablets. It plays structured workouts on your Bluetooth FTMS smart trainer in ERG mode, and turns every interval into a place to ride through.

Website: https://cranklands.cyclear.nl

This repository is where you tell us what works, what doesn't and what you'd like next. The app's source code is not here.

## Give feedback

| You want to… | Go to |
|---|---|
| Report something that's broken | [Report a bug](https://github.com/ErikTrapman/cranklands/issues/new?template=bug_report.yml) (Issues) |
| Suggest a feature, workout or world | [Ideas](https://github.com/ErikTrapman/cranklands/discussions/categories/ideas) (Discussions) |
| Ask how something works | [Q&A](https://github.com/ErikTrapman/cranklands/discussions/categories/q-a) (Discussions) |
| Say a trainer works (or doesn't) | [Q&A](https://github.com/ErikTrapman/cranklands/discussions/categories/q-a), with the make and model |

Search the [open issues](https://github.com/ErikTrapman/cranklands/issues) and [discussions](https://github.com/ErikTrapman/cranklands/discussions) first. If someone already posted it, a 👍 on the first post helps us decide what to fix and build next.

In the app, **Settings › About › Send feedback** opens a page with these links. A bug report started from there already has your app version filled in.
